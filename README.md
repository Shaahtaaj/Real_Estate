# Memon Estate

Premium real estate listing platform scaffold for XAMPP/PHP.

## Current Build

- MVC folder structure
- Tailwind-powered responsive dark luxury UI
- Home, listings, property details, auth, dashboard, admin, about, contact
- Functional JSON-backed demo storage for listings, users, favorites, inquiries, approvals
- Working user dashboard and admin dashboard
- Glassmorphism components, hover effects, skeleton loaders, AOS/GSAP hooks
- Leaflet map placeholder, Chart.js admin analytics, SweetAlert2 toast
- PWA manifest, root service worker, offline page, install prompt, mobile bottom app navigation
- MySQL schema for users, properties, images, favorites, inquiries, reviews

## Run Locally

With XAMPP Apache running, open:

```text
http://localhost/Real_Estate/
```

Alternative PHP built-in server:

From the project root:

```powershell
php -S localhost:8000 -t public
```

Then open `http://localhost:8000`.
